# my-first-pr

첫 번째 Pull Request(PR)를 연습하기 위한 저장소입니다.

## 목적

- 브랜치 생성 → 커밋 → 푸시 → PR 생성의 전체 흐름을 익힙니다.
- 작고 안전한 변경(문서 수정, 오타 수정, 테스트 추가)으로 연습합니다.

## 시작하기

```bash
git clone https://github.com/Han-Keul/my-first-pr.git
cd my-first-pr
```

## 기여 방법

1. 새 브랜치를 만듭니다: `git checkout -b <브랜치-이름>`
2. 변경 사항을 커밋합니다: `git commit -m "변경 내용 요약"`
3. 브랜치를 푸시합니다: `git push -u origin <브랜치-이름>`
4. GitHub에서 Pull Request를 엽니다.
